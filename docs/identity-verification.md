# Identity verification
The portal models verification as a provider-neutral status with append-only events. The identity provider feature is disabled unless both the feature flag and provider key are present. Failed or unavailable automated verification must route to controlled manual review, not auto-approval.

Configurable policy: provider, assurance level, evidence fields, expiry, re-verification, and reviewer workflow. Te controleren met jurist/boekhouder: KYC, AML, discrimination, and biometric-data obligations.
